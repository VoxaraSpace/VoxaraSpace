# Contributing

Bug reports and pull requests are welcome for the app, the SDK and the
examples.

- **Bugs**: open an issue with the build number (Settings, About), what you
  did, what happened and what you expected. Screenshots help.
- **Changes**: keep pull requests focused on one thing. Run the app from
  source (`cd client && npm install && npm start`) and check the change in
  the real app before sending it.
- **Security problems**: not in the issue tracker. See SECURITY.md.
- **Protocol changes**: the app can only use what the service provides. If a
  change needs something new from the server, open an issue first so it can
  be planned on both sides.

Be decent to each other in issues and reviews. Contributions are accepted
under the Apache License 2.0, the same licence as the rest of the code.
